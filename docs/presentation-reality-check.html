Section 1 — Technical Description & System Design

Presentation Claim

“Three main parts: web portal, secure backend, dedicated AI service”

Built with separate independent blocks, reliable, easy to update, secure against data loss.

Codebase Reality

5 apps + 1 shared lib: frontend (public web), mobile-pwa (installable PWA), admin-portal (admin dashboard), backend (Laravel), ai-service (Python FastAPI), shared (common UI, types, API client).

Partial mismatch — script undersells. The true count is 5 services, not 3. The mobile-pwa and admin-portal are distinct first-class apps. This is actually a stronger story — update the script to reflect it.
Presentation Claim

“Works smoothly even without stable internet”

Perfect for coastal and farming towns.

Codebase Reality

Offline queue (IndexedDB + localStorage), service worker with stale-while-revalidate, offline fallback page, background sync for queued reports. Fully real.

Verified — genuinely implemented

Section 3 — Ghost Mode & Anonymization

Presentation Claim

“Ghost Mode strips all hidden tracking data & replaces with anonymous ID”

EXIF stripped, GPS fuzzed, identity hidden.

Codebase Reality

Fully implemented across the entire stack:

• Client-side EXIF stripping via canvas re-encode (all 3 Next.js apps)
• Server-side EXIF stripping via Imagick + GD fallback (Laravel)
• GPS fuzzing via LocationFuzzService (snaps to nearest barangay centroid)
• Anonymous user ID 00000000-0000-0000-0000-000000000000
• Theme changes (navy page, gold accent, teal secondary)
• Timeline masking for ghost reporters
• Notification suppression for ghost users

Fully verified — this is the most complete feature in the codebase
Presentation Claim

“exact camera details and specific phone location records stripped before the report is sent”

EXIF removal at capture time.

Codebase Reality

exif-stripper.ts (shared) provides stripExif() and stripExifFromFile(). Called in report/page.tsx and camera-test/page.tsx. The exif_removed_at timestamp is stored on every TicketEvidence record. Server-side also re-strips as a secondary step.

Fully verified

Section 4 — UN SDG Alignment

Codebase Reality

Zero SDG references exist anywhere in the codebase. No SDG model, no SDG dashboard, no SDG filtering, no SDG-CSR attribution per report. The only implicit connection is that the app is environmentally-focused.

Tested stability under real-world conditions.

Count is unverifiable. What exists:

Unverifiable — real count is likely ~15-20. Either write 57 tests or lower the number.

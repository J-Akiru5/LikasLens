Architecture: before vs after

Before: Two processes (apps/backend Laravel on :8000 + apps/ai-service FastAPI on :8001), PHP ↔ Python HTTP calls on every request, Sanctum + Supabase dual auth, GD extension for EXIF stripping.

After: One Python service on :8001. Direct in-process AI calls. Supabase JWT-only auth. Pillow EXIF strip. Single Docker image. One deploy.

03 — Phase 0

Unblock: verification gates

Before the service can be tested end-to-end, these infrastructure checks must pass. The agent cannot log into Supabase, Neo4j Aura, or Google AI Studio for you.

01
Supabase — is the project awake, and is the data there?

Free-tier projects pause after ~7 days idle but restore intact. Log in, unpause if needed, then run row counts on reports, tickets, environmental_laws_ph, users. Take a pg_dump backup. Blocker if failed: total — nothing else can proceed.

02
Neo4j Aura — does the graph still exist?

Aura Free auto-pauses on inactivity and deletes after ~30 days. If gone: provision a fresh Free instance and re-seed from ai-service/seed_neo4j.py. Blocker if failed and unrecoverable: severe — the symbolic routing claim depends on this. Fallback: PostgreSQL rule-based routing (already implemented as POSTGRESQL_ROUTING_RULES in triage_service.py).

03
Gemini API key — does it still authenticate?

Test with a single curl. Confirm nothing in GCP is still accruing charges. Blocker if failed: moderate — issue a new key from AI Studio on a clean project.

04
FastAPI service — does it start and connect to Supabase PostgreSQL?

Set DATABASE_URL, SUPABASE_JWT_SECRET, and storage credentials in apps/ai-service/.env. Run cd apps/ai-service && python -m uvicorn main:app --reload --port 8001. Confirm curl localhost:8001/health returns {"status":"ok"}. Blocker if failed: check DATABASE_URL format (postgresql+asyncpg://...).

06 — Standing rules

Rules that survive the whole sprint

Single service

apps/ai-service is the only backend. No other service to deploy, monitor, or debug. The old apps/backend has been deleted — don't recreate it.

No Turborepo before Sep 3

It's a build-cache layer. It ports zero endpoints and introduces a new way for the Vercel deploy to break. October problem.

One identity provider

Supabase Auth only. No Sanctum, no laravel_token, no second bearer. auth/supabase_jwt.py is the single JWT verifier — don't add alternatives.

Ghost Mode is sacred

Identity strip + location fuzzing runs on every report, ghost or not. EXIF stripping via Pillow happens before any image touches storage or YOLO. Never negotiate this.

Mirror the JSON exactly

The frontend is not being rewritten, so every ported handler must return {success, data, meta} matching the old controller shape. Read the Laravel controller before writing the handler.

The demo script is the spec

docs/demo-script.md defines what exists. Not the README, not the roadmap docs, not what the platform could theoretically do. If it isn't in the script, it isn't in scope.

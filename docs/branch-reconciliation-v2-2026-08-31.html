10. Lessons Learned

Merge Reintroduced Fabrication

The map branch was based on pre-v2-fix code. Merging it into development reintroduced hardcoded sparklines and fabricated metric fallbacks that the v2 sweep had already cleaned. The fabrication-pattern re-sweep (standing protocol) caught this immediately — this is why the re-sweep exists.

Implication: Any branch created before a fix lands will reintroduce the old patterns when merged. The re-sweep must run after every merge, not just after the original fix.

Pre-Existing Type Error Fixed

ActivityFeedItem.type expected "Critical" | "Warning" | "Info" but the mobile-pwa dashboard mapped to "Notice" | "Urgent" | "Important". This was a pre-existing error on development, fixed as part of this reconciliation since it's presentation-critical.

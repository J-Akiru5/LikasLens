📋 Report Submission Sequence

Step-by-step flow from capture to resolution

1
Capture
Citizen opens /report page on PWA. Camera activates via getUserMedia API. GPS coordinates acquired via navigator.geolocation. Photo captured as base64 JPEG on canvas.
Citizen Frontend
2
Ghost Mode Check
If Ghost Mode active: EXIF metadata stripped via canvas re-encode. User ID not sent. Reports owned by sentinel anonymous UUID. UI switches to dark stealth theme.
Frontend
3
Pre-submission Triage
POST /api/reports/triage sends image to AI Service. YOLOv8 runs inference, returns environmental_assessment. If high-risk detected, "Edge Interceptor" modal warns citizen and recommends Ghost Mode.
Frontend Backend AI Service
4
Report Submission
POST /api/reports with base64 image + GPS + user_id. Laravel validates payload, computes SHA-256 checksum, uploads image to Supabase Storage at evidence/YYYY/MM/DD/.
Backend Storage
5
Database Transaction
Creates Ticket (status: open), TicketEvidence (storage path, checksum, MIME), and Report record. All within a single DB transaction for atomicity.
Backend PostgreSQL
6
AI Classification
Outside transaction (report survives if AI is down). YOLOv8 detects objects → Gremlin traverses hazard→law→agency → Gemini generates 2-sentence incident summary. Results stored as TicketClassification.
YOLOv8 Gremlin Gemini Backend
7
Impact Scoring
Credential Service evaluates criteria (report_count, yolov8_class). Tier Service checks for tier advancement. Eco-credit bonuses awarded from corporate-funded CreditPool. Credits deposited to CitizenWallet.
Backend PostgreSQL
8
Analyst Review
Analyst views ticket list, opens detail with evidence photos + AI classification. Assigns ticket to appropriate NGO via POST /api/ticket-assignments with assignment_reason.
Analyst Backend
9
Resolution
NGO receives assignment, investigates, marks ticket resolved. LGU verification triggers "lgu_verified_count" achievement for citizen. Dashboard calculates average response time for public accountability.
NGO Backend Frontend

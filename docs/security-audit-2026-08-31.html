6. Notes on Trivy Container Scan

The GitHub Actions workflow (.github/workflows/security-scan.yml) runs Trivy against the AI service Docker image weekly. The container scan covers OS-level packages (python:3.12-slim base image) and Python dependencies. Key points:

  • The Dockerfile uses python:3.12-slim which receives regular security updates
  • apt-get upgrade -y is run at build time to patch OS-level CVEs
  • Python dependencies use version ranges (e.g., fastapi>=0.115.0,<1.0.0) which allow automatic patch updates
  • Trivy cannot be run locally on this Windows dev machine — the full container scan runs in CI

02 · Workflows

Core Workflows

The primary data flows through the LikasLens platform, from citizen report submission to resolution.

Workflow 1: Citizen Report Submission

End-to-End Report Flow
01
Capture
Citizen opens /report. Camera activates, GPS auto-tags location. Ghost Mode strips EXIF metadata.
→
02
Triage
POST /reports/triage sends base64 image to AI service for pre-check. YOLOv8 detects environmental concerns.
→
03
Edge Intercept
If hazards detected, EdgeInterceptorModal warns user. User can proceed (auto-enables Ghost Mode) or cancel.
→
04
Store
POST /reports → Laravel creates Ticket + TicketEvidence + Report rows. Image stored in Supabase Storage.
→
05
AI Analyze
TriageService sends image to AI service. YOLOv8 classifies objects. TicketClassification rows created.
→
06
Achieve
AchievementService evaluates criteria (report_count, yolov8_class). RankService checks for level-up. Eco-credits awarded.

Workflow 2: Neuro-Symbolic AI Pipeline

Dual-Layer AI Processing
NEURAL
YOLOv8 Detection
Pre-trained model detects 80+ object classes. Environmental indicators mapped: litter, vehicles, sanitation, vegetation, infrastructure.
→
SYMBOLIC
Gremlin Traversal
Graph query: g.V(hazard).out('violates').out('enforced_by') → maps hazard → law → enforcement agency.
→
NEURAL
Gemini Summary
Gemini 2.5 Flash generates 2-sentence formal incident report naming specific laws and agencies from graph data.
→
OUTPUT
Classification
TicketClassification stored with violation_type, confidence_score. Triage summary written to ticket.

Workflow 3: Authentication Flow

Supabase Auth + Laravel Sanctum
01
Login
User signs in via Supabase Auth (email/password or social login). Supabase returns JWT session.
→
02
Sync
Frontend calls POST /auth/sync with supabase_auth_user_id, email, name. Laravel creates/updates User row.
→
03
Token
Laravel returns Sanctum bearer token. Stored in httpOnly cookie. All subsequent API calls authenticated via Authorization: Bearer.
→
04
RBAC
Middleware enforces roles: citizen, analyst, super_admin, ghost. Analyst+ can verify reports. Super admin has full CRUD.

Workflow 4: Admin Ticket Management

Analyst → NGO Assignment → Resolution
01
Review
Analyst views tickets in admin portal. Filters by status, searches by title/description. Sees AI triage summary and confidence.
→
02
Assign
Analyst assigns ticket to NGO group via POST /ticket-assignments. Assignment reason recorded.
→
03
Investigate
NGO receives assignment. Status transitions: open → investigating → monitoring → resolved/closed.
→
04
Verify
LGU verification triggers POST /reports/verify. Achievement hooks fire: lgu_verified_count evaluated. Citizen rewarded.

Workflow 5: Achievement & Reward System

Points → Ranks → Eco-Credits → Rewards
EARN
Points
Actions trigger AchievementService: report submission, YOLO class detection, offline sync, LGU verification, geofence verify.
→
RANK
Level Up
RankService calculates level: Citizen (0-99) → Observer (100-999) → Steward (1K-4.9K) → Guardian (5K-9.9K) → Eco Champion (10K+).
→
BONUS
Eco-Credits
Rank-up triggers eco-credit bonus from CreditPool (ESG sponsor). Credits deposited into CitizenWallet.
→
REDEEM
Rewards
Citizens redeem credits for rewards from RewardsCatalog at PartnerStores. Redemption tracked in RewardRedemption ledger.

10 · Security

Security & Ghost Mode

Zero-knowledge protection for environmental whistleblowers reporting sensitive violations.

👻

Ghost Mode Protocol

EXIF Stripping: Canvas redraw removes GPS, device ID, timestamp before transmission.
Anonymous Submission: Reports sent without user_id. Ghost user created with UUID 00000000-....
Theme Toggle: Global data-theme="ghost" attribute triggers visual feedback across all pages.
Edge Interceptor: AI-detected hazards auto-trigger Ghost Mode warning modal.

🔒

API Security

Sanctum Auth: Bearer token authentication for all protected endpoints.
RBAC: Role middleware — citizen, analyst, super_admin, ghost.
Rate Limiting: Per-endpoint throttling (5-20 req/min for auth, 10-60 for AI).
CORS: Environment-driven origin whitelist.
Input Validation: Laravel request validation on all endpoints.

🛡️

AI Service Security

Gremlin Injection: Input sanitization with regex validation on all graph IDs.
String Escaping: All Gremlin query strings escaped for special characters.
Rate Limiting: In-memory per-IP rate limiting with strict limits on expensive endpoints.
Request Logging: Every request logged with timing, status, and request ID.

📋

Audit Trail

Audit Logs: All admin actions recorded with actor, entity, old/new values, IP, user agent.
Evidence Chain: SHA-256 checksums on all uploaded evidence. EXIF removal timestamp tracked.
Point Ledger: Full transaction history for reward points with balance_after tracking.

Multi-tier reward system driving citizen engagement through achievements, ranks, and eco-credits.

Achievement Criteria Types

12 · Offline-First

Offline-First PWA

Three-tier caching strategy with IndexedDB report queue for 100% data retention in low-connectivity environments.

Service Worker Caching

Cache-First: Static assets (JS, CSS, images) served from cache, updated in background.
Stale-While-Revalidate: API responses served from cache, refreshed asynchronously.
Network-First: Critical API calls (auth, submission) try network, fall back to cache.

IndexedDB Report Queue

Queue: Reports stored in likaslens-offline IndexedDB with report-queue object store.
Fallback: localStorage backup if IndexedDB unavailable.
Flush: On online event, queued reports automatically synced via POST /reports.
Achievement: offline_sync criteria evaluated on successful batch sync.

Network Detection

Online/Offline Events: Real-time connectivity monitoring.
UI Feedback: Offline banner displayed when connection lost.
Toast Notifications: "Connection restored. Syncing queued reports." on reconnect.

Installability

PWA Manifest: Full manifest with icons, theme color, display mode.
Install Prompt: beforeinstallprompt event captured. Custom install CTA on landing page.
Home Screen: Appears as native app on mobile home screens.

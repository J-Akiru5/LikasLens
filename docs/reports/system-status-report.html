Q&A Cheat Sheet — Layman vs Technical Terms
Translate jargon to plain English for tomorrow's virtual presentation. Click each item to practice your answer.
15 Cards
Say this Monorepo

Layman: All our apps live in one shared project folder, like a neighborhood where houses share a common garage and mail room.

Technical: pnpm workspace monorepo with 6 packages under apps/. Single pnpm install installs all dependencies. Shared TypeScript types, API client, and UI components via @likaslens/shared.

Say this The 5-App Architecture

Layman: We built five separate tools — a public website, a phone app, an admin dashboard, a brain (AI), and a backbone (data API). They talk to each other like a team using walkie-talkies.

Technical: Frontend (Next.js, Vercel), Mobile PWA (Next.js + service worker), Admin Portal (Next.js, desktop-first), Backend (Laravel 12, PostgreSQL, Cloud Run), AI Service (FastAPI, YOLOv8, Neo4j, Cloud Run). Communication via REST JSON only.

Say this What LikasLens Does

Layman: Citizens take a photo of an environmental issue (like illegal dumping or flooding). The app automatically identifies the problem, checks which laws apply, and routes it to the right government office — all in seconds.

Technical: Upload → EXIF stripping → YOLOv8 + Roboflow inference → neuro-symbolic reasoning (16 PH laws, 18 hazard classes) → triage disposition (auto_routed / pending_review / auto_dismissed) → notification dispatch.

Likely Q YOLOv8 / AI Detection

Layman: We trained a computer to recognize environmental hazards the way you'd teach a child to spot different animals — by showing it thousands of examples until it learns the patterns.

Technical: Ultralytics YOLOv8 fine-tuned on custom + Roboflow datasets. Composite scoring: max(coco_score, env_score) * 0.7 + agreement * 0.3. 3-retry Gemini fallback with exponential backoff (1s/2s).

Likely Q PWA vs Native App

Layman: Our mobile app isn't in the app store — it's a website that behaves like an app once you save it to your home screen. Like a bookmark that can send you notifications and work offline.

Technical: Progressive Web App using @ducanh2912/next-pwa v10.2.9. Service worker for offline caching, manifest for install prompt. No App Store/Play Store submission required. Known issue: Android logo (#175) and ownership (#176) still broken.

Likely Q Multi-Tenancy

Layman: Each city government sees only their own citizens' reports — like separate filing cabinets for different offices. No one accidentally sees someone else's data.

Technical: Laravel TenantScope pattern. ResolveTenant middleware extracts tenant from subdomain/JWT. All 22 models scoped globally. PostgreSQL Row-Level Security as backup.

Likely Q Neuro-Symbolic AI

Layman: The AI doesn't just guess — it combines visual recognition (seeing a problem) with a rulebook (laws, jurisdiction) to make a logical decision, not just a statistical one.

Technical: Hybrid pipeline: YOLOv8 neural detection → symbol grounding → Neo4j graph query (16 PH laws, hazard-Law edges). Decision logic uses graph traversal for jurisdiction routing, not pure ML classification.

Likely Q Neo4j Graph Database

Layman: Instead of storing data in spreadsheets (tables), we store it like a mind map — laws connect to hazards, hazards connect to government agencies, agencies connect to locations. Makes "which office handles this?" instant.

Technical: Neo4j AuraDB. Nodes: Law (16), Hazard (18), NGO (5), Region. Edges: HAZARD_VIOLATES_LAW, AGENCY_ENFORCES, LOCATED_IN. Graph traversal with Cypher queries for jurisdiction routing.

Context EXIF Stripping & Privacy

Layman: When you take a photo, your phone secretly embeds your GPS location and device info into the image file. We strip that data before sending it to the server — like shredding the envelope before passing the letter.

Technical: Client-side EXIF stripping via JavaScript canvas.toBlob() re-encoding. Strips GPS, device model, timestamp before upload. Raw originals preserved on device only — only stripped copies transmitted.

Context Ghost Mode (Zero-Knowledge)

Layman: Whistleblowers can submit evidence without revealing their identity — even we can't see who they are. Like a confidential tip hotline that genuinely can't trace the caller.

Technical: Ghost mode bypasses auth for report submission. No user ID attached to ghost reports. Background image caching fixed (Lou branch merged). Server never receives device fingerprint, IP is not logged.

Context i18n — 10 Languages

Layman: The app speaks 10 Southeast Asian languages — English, Filipino, Vietnamese, Indonesian, Malay, Tamil, Thai, Khmer, Burmese, and Lao. Users can switch anytime, like flipping a toggle.

Technical: next-intl@4.13.0 pinned via pnpm overrides (fixes dual-version context bug). Shared message files under apps/shared/locales. Locale type union: 'en'|'fil'|'vi'|'id'|'ms'|'ta'|'th'|'km'|'my'|'lo'.

Say this Deployment (Vercel + Cloud Run)

Layman: The websites auto-deploy when we push code — like a self-service vending machine. Our backend and AI run on Google's servers and scale automatically when traffic spikes.

Technical: Frontend/Mobile/Admin on Vercel (git push → deploy). Backend & AI Service on GCP Cloud Run (Docker build → Artifact Registry → Cloud Run via CI/CD). 2 GCP workflows (backend + ai-service). Vercel outputDirectory bug was FIXED.

Say this The GD Extension Fix

Layman: Our backend needed a special image-processing library that wasn't installed on the server. Like buying a new printer and realizing the driver software isn't installed — now it's fixed.

Technical: PHP GD extension was missing from the Docker image. Fixed by adding libpng-dev libjpeg-dev libfreetype6-dev + docker-php-ext-configure gd in all 3 build stages. Also added extension_loaded('gd') guard in ReportController.

Likely Q Current Weaknesses

Layman: We have 19 known issues — mostly visual glitches on the mobile app, and Google login doesn't work yet. The backend needs one more deployment with our latest fixes. None are data-loss risks.

Technical: 10 mobile UI bugs (layout/overlap), 2 auth bugs (#162 Google login, #177 session persistence), 1 OG image. Backend Docker needs redeployment with GD + APP_KEY. 1 Gremlin ref remains. AI service evaluation (FPR) not yet validated.

Context Triage Disposition System

Layman: Not every report needs a human to look at it. The AI sorts incoming photos into three buckets: good evidence gets routed to the right office automatically, unclear ones wait for a human reviewer, and spam/pranks get discarded.

Technical: Three-way classifier output: auto_routed (high confidence + clear law match → direct dispatch), pending_review (ambiguous → human-in-loop), auto_dismissed (low confidence / no violation → silent discard). Configurable thresholds.

Section 02

Priority Framework

Ruthlessly prioritized. If it doesn't serve the demo loop, it waits.

🔴 P0
SHIP OR DIE
These are the only things allowed to block the MVP.
📸
Citizen Reporting UI
Lou
  • Preserve existing polished reporting UI
  • Simplified, fast flow — no bloat
  • Photo upload with evidence capture
  • Location picker (GPS + manual)
  • Basic incident description field
  • Standard / Ghost Mode selector
  • Clear submission progress state
⛔ Hard boundary: No reward points, gamification, scoreboards, achievements, or social mechanics.
👻
Ghost Mode
Both
  • Uses the same report flow — no secondary workflow
  • Clear Ghost Mode activation trigger
  • Strong visual privacy state ("Your identity will not be attached")
  • Reporter identity separation on payload
  • Public/LGU payload excludes identifying info
  • Backend enforcement (Jeff)
⛔ Must not create a confusing secondary workflow. Same flow, different trust level.
🧠
Real AI Analysis
Jeff
  • Local YOLOv8 inference — first pass
  • Cloud Gemini — deep analysis
  • Frontend agnostic: never expose which model is thinking
  • Structured JSON output with category, severity, confidence
  • Clean analysis state display for Lou to consume
Analyzing evidence... ✓ Environmental incident detected ✓ Category identified ✓ Severity assessed ✓ Responsible office recommended
🔀
Routing Intelligence
Jeff
  • Neo4j graph recommendation — primary path
  • PostgreSQL rule fallback — always resolves
  • Output is always a "Recommended routing", never a mandate
  • LGU officer can Accept, Reassign, or Reject
  • Human-in-the-loop proven at every step
⚠️ The AI does not have final authority. Always surface as recommendation, not decision.
🏛
LGU Command Center
Lou
  • A fool-proof action center — not an enterprise dashboard
  • Primary screen answers: What? Where? AI says? What do I do?
  • No dense tables as primary experience
  • Large readable typography, clear visual hierarchy
  • Action flow: NEW → REVIEW → VERIFY → ACTION TAKEN → RESOLVED

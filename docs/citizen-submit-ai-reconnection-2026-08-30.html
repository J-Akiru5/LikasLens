1. Problems Found

PROBLEM Client.ts intercepted all report submissions

routeRequest("reports", "POST", body) at client.ts:325-382 inserted directly into Supabase's tickets table, completely bypassing the AI service. No EXIF stripping, no YOLO triage, no Neo4j routing.

PROBLEM Triage was a hardcoded stub

routeRequest("reports/triage", ...) at client.ts:316-322 returned {has_concern: false, indicators: []} with zero AI involvement. Citizens never saw pre-submission warnings.

PROBLEM Ghost mode never reached the server

The report payload never included ghost_mode. The server-side sanitize_report_payload() (which strips identity + fuzzes location) was never invoked for citizen submissions.

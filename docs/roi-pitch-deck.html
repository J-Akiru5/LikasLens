Zero-knowledge reporting. EXIF stripped client-side. No user_id, no IP log, no device fingerprint. Nothing to subpoena.

Gamified progression from Novice → Eco-Guardian → Environmental Champion. Status, recognition, and real rewards.

Every report generates a ticket with a display ID (e.g. INC-019EFC). Citizens track resolution in real time. The system routes to the correct agency automatically — the citizen doesn't need to know which law was broken or who enforces it. That's the ROI of being heard.

Offline-First Access

PWA with IndexedDB queue. File a report without internet. It syncs when connectivity returns. No app store required. Works on $100 Android phones. 12M Filipino fisherfolk can participate today.

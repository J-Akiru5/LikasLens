8. Visual Alignment Summary

Public frontend → Admin portal visual contract established:
  • Typography: Both apps now load Bricolage Grotesque (display), Public Sans (body), JetBrains Mono (data)
  • Color system: Both apps use the same CSS custom properties from design-tokens.css
  • Ghost Mode: Both apps share the same data-theme="ghost" switching mechanism and token overrides
  • Component language: Both apps share btn-primary-dark, hero-card, feature-card, label-pill-dark, ec-grid, and other utility classes
  • Liksi: Both apps use the same LiksiChat component from @likaslens/shared
  • Brand identity: Both apps display the same LikasLens wordmark, logo, and visual personality
Design distinction preserved: The admin portal remains operationally dense with sidebar navigation, KPI cards, kanban boards, and data tables — it does not look like the citizen-facing marketing site. The alignment is about shared visual DNA, not identical layouts.

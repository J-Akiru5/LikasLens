Part 1: Blockchain Evidence Hashing

Tamper-proof, government-verifiable, privacy-respecting evidence chain

What Is Blockchain (Simple Explanation)

Think of blockchain as a public notebook that nobody can erase. Once you write something in it, it's there forever — no one can change it, delete it, or pretend it was never written. Not you, not the government, not even us.

When we "put evidence on blockchain," we're not putting the photo itself there. We're putting a fingerprint (called a hash) — a 64-character string that uniquely identifies the evidence.

How a hash works: Photo of illegal dumping ──→ SHA256 algorithm ──→ a1b2c3d4e5f6789... The SAME photo always produces the SAME hash. Even a 1-pixel change produces a COMPLETELY DIFFERENT hash. So if someone tries to alter the photo later, the hash won't match — tampering detected!

Can the Government Access It?

Yes — and that's the whole point.

  • Public — anyone can read the blockchain, no permission needed
  • Immutable — nobody can delete or alter entries
  • Decentralized — no single point of failure
  • Verifiable — government can independently verify any report

The government doesn't need special access. They just need the report ID and a blockchain explorer like Polygonscan.

Normal Mode vs. Ghost Mode

Normal Mode

  • Photo on server: linked to user
  • EXIF: stripped
  • Blockchain: proves evidence integrity
  • Government sees: who reported + evidence

Ghost Mode (Privacy First)

  • Photo on server: anonymous (no user link)
  • EXIF: stripped
  • Blockchain: proves evidence integrity
  • Government sees: evidence only
  • Reporter identity: invisible to everyone

The Analogy

Think of it like a sealed evidence box in a police station:
  • The box contains the photo and evidence (your server)
  • The box has a timestamp and case number stamped on the outside (blockchain)
  • The box is sealed with tamper-evident tape (hash verification)
  • Nobody knows who dropped off the box (Ghost Mode)
  • The evidence inside is real and verifiable
  • But the identity of the person who dropped it off is unknown
Blockchain = tamper-evident tape. Ghost Mode = anonymous drop-off.

Can the Government Force You to Reveal the Reporter?

If Ghost Mode is properly implemented, there is nothing to reveal:

  • Database: user_id is NULL for Ghost Mode reports — no link exists
  • Blockchain: Contains only the evidence hash — no reporter info
  • Server logs: Configured to NOT log Ghost Mode submissions with IP/session info
  • Even you (the platform owner) cannot reveal the reporter's identity

This is the "zero-knowledge" promise — the same principle behind anonymous tip lines, but with cryptographic proof that the evidence is real.

Part 3: AR Camera Overlay (Evidence Stamp)

Professional-grade evidence capture with embedded metadata

What It Looks Like

┌─────────────────────────────────────┐ │ 🔴 EVIDENCE CAPTURE │ ← Label │ │ │ │ │ [Camera Viewfinder] │ ← Live camera feed │ [Illegal dumping site] │ │ │ │ │ │ 📍 14.5995°N, 120.9842°E │ ← GPS coordinates │ 🕐 2026-06-10 14:32:07 │ ← Timestamp │ 👻 Ghost Mode: ON │ ← Privacy status │ 📋 Report #LL-2026-00142 │ ← Report ID └─────────────────────────────────────┘ This overlay is BAKED INTO the captured photo. It becomes permanent part of the evidence.

How It Works

When the citizen captures a photo, the app draws the camera frame onto a <canvas> element, then stamps the metadata on top. The exported JPEG contains the overlay permanently.

What You CAN'T Do in PWA

True AR (placing 3D objects in the real world, like Pokemon Go) requires native APIs (ARCore for Android, ARKit for iOS). This is not available in PWAs. For a PWA, the canvas stamp approach is the best option — and honestly, it's what matters for evidence integrity anyway.

Why This Matters

  • Evidence integrity: Metadata is permanently part of the photo — can be cropped out but proves original context
  • Professional appearance: LGUs take stamped evidence more seriously than raw phone photos
  • Body camera effect: Same approach used by law enforcement body cameras and dashcams
  • Court admissibility: Stamped evidence with GPS + timestamp is stronger in legal proceedings

Step 5 — Create the BlockchainService

Create apps/backend/app/Services/BlockchainService.php:

<?php

namespace App\Services;

use Illuminate\Support\Facades\Log;

class BlockchainService
{
    private string $rpcUrl;
    private string $privateKey;
    private string $walletAddress;

    public function __construct()
    {
        $this->rpcUrl = config('services.blockchain.rpc_url');
        $this->privateKey = config('services.blockchain.private_key');
        $this->walletAddress = config('services.blockchain.wallet_address');
    }

    /**
     * Create a SHA256 hash from evidence metadata.
     * Only non-identifying data is included.
     */
    public function hashEvidence(array $metadata): string
    {
        $payload = json_encode([
            'location' => $metadata['latitude'] . ',' . $metadata['longitude'],
            'type' => $metadata['report_type'] ?? 'unknown',
            'severity' => $metadata['severity'] ?? 'unknown',
            'ai_class' => $metadata['ai_classification'] ?? 'unknown',
            'timestamp' => $metadata['timestamp'],
            'report_id' => $metadata['report_id'],
        ], JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE);

        return hash('sha256', $payload);
    }

    /**
     * Submit evidence hash to Sepolia testnet.
     * Returns the transaction hash on success.
     */
    public function submitToBlockchain(string $evidenceHash): ?string
    {
        try {
            // The hash is stored as "data" in the transaction
            // This is the cheapest way to put data on-chain
            $web3 = new \Web3\Web3($this->rpcUrl);

            // Build and sign transaction
            // For the hackathon demo, a simplified approach:
            // Use a REST API to submit the transaction
            $response = \Http::post($this->rpcUrl, [
                'jsonrpc' => '2.0',
                'method' => 'eth_sendRawTransaction',
                'params' => [$this->signTransaction($evidenceHash)],
                'id' => 1,
            ]);

            if ($response->successful()) {
                $txHash = $response->json('result');
                Log::info('BlockchainService: Evidence hash submitted', [
                    'evidence_hash' => $evidenceHash,
                    'tx_hash' => $txHash,
                ]);
                return $txHash;
            }

            Log::warning('BlockchainService: Submission failed', [
                'response' => $response->body(),
            ]);
            return null;
        } catch (\Throwable $e) {
            Log::error('BlockchainService: Error', [
                'error' => $e->getMessage(),
            ]);
            return null;
        }
    }

    /**
     * Get the public blockchain explorer URL for a transaction.
     */
    public function getExplorerUrl(string $txHash): string
    {
        return "https://sepolia.etherscan.io/tx/{$txHash}";
    }

    /**
     * Verify a transaction exists on the blockchain.
     */
    public function verifyTransaction(string $txHash): bool
    {
        $response = \Http::post($this->rpcUrl, [
            'jsonrpc' => '2.0',
            'method' => 'eth_getTransactionByHash',
            'params' => [$txHash],
            'id' => 1,
        ]);

        return $response->successful()
            && $response->json('result') !== null;
    }

    private function signTransaction(string $data): string
    {
        // Simplified signing for demo purposes
        // In production, use web3p/web3.php for proper signing
        // This creates a minimal transaction with the hash as data
        return '0x' . $data; // Placeholder - implement with web3p
    }
}

Part 7: FAQ & Common Questions

Answers to the most asked questions about blockchain + Ghost Mode

Q: If blockchain is public, does it reveal who reported it?

No. We only put the evidence fingerprint (a 64-character hash) on the blockchain — NOT the photo, NOT the reporter's name, NOT their IP, NOT their device. The hash proves "this evidence existed at this time" without revealing who created it.

Q: Can the government identify the reporter?

No. In Ghost Mode: the database has user_id = NULL (no link exists), the blockchain has only the evidence hash (no reporter info), and server logs don't record IP addresses for Ghost Mode submissions. Even the platform owner cannot reveal the reporter's identity.

Q: Does it cost money?

No. On Sepolia testnet (for demo): completely free. On Polygon mainnet (for production): ~$0.001 per transaction. You can submit 1,000 evidence hashes for $1.

Q: Do citizens need a crypto wallet?

No. The backend handles everything. Citizens just take a photo and submit. They see "Evidence verified ✓" — no crypto, no wallet, no complexity.

Q: What if the blockchain goes down?

Blockchains don't go down — they're decentralized across thousands of nodes worldwide. Even if your server is offline, the evidence hashes remain permanently on the blockchain.

Q: Can someone fake a blockchain entry?

No. To fake an entry, you'd need to control 51% of all the computers running the blockchain — that's millions of machines. It's computationally impossible.

Q: Is this hard to implement?

No. The entire implementation is: 1 PHP service class (~80 lines), 1 migration (add 2 columns), 1 controller method, and 1 config entry. No servers, no accounts, no payments. Just code.

Q: Can the government force us to reveal the reporter?

There is nothing to reveal. The database has no user link for Ghost Mode reports. The blockchain has no reporter info. Even with a court order, we can only show: "A report was submitted by someone, at some time, with this evidence." The reporter's identity simply does not exist in any data we store.

8. Known Issues

Configuration Gap

Admin Portal missing RENDER_AI_URL: The admin portal's AI health endpoint returns "primaryUrl": "(not configured)". This means the admin portal's AI proxy routes (chat, ticket status) cannot reach the Render AI service directly. The ticket status endpoint works because it goes through a different proxy path.

Impact: Admin portal chat/AI features may not work.

Fix: Set RENDER_AI_URL in the admin portal's Vercel environment variables.

Render Free Tier Cold Start

Direct Render access times out (~90s) when the service is sleeping. The keep-warm cron job runs every 10 minutes but doesn't guarantee availability. Proxy routes through Vercel handle this with a 5s timeout and fallback behavior.

Impact: First request after idle may fail. Subsequent requests succeed.

Mitigation: Keep-warm workflow active. 120s timeout configured in frontend/mobile-pwa.

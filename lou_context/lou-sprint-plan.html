Section 01

Strategic Context

Decisions from Jeff's war plan + advisor meeting (Aug 25) + Lou's improvements.

🚫
Gamification Removed
  • Advisors (Zeno & Ann) explicitly said to remove it
  • "Citizens need a reliable platform, not incentivization"
  • Makes app look serious, not like a game
  • Frees up time for core features
🌊
Water Monitoring Scope
  • Focus on clean rivers and water waste
  • Not broad environmental — narrow and deep
  • Align with CENRO / MENRO offices
  • UI copy should emphasize water/waste
💰
Subscription Licensing
  • ₱1-5M/year LGU license, 3-year terms
  • Aligned with October budget planning
  • Admin portal must feel enterprise-grade
  • These are paying government clients
🎯
Pitch = The Demo Loop
  • Citizen → AI → LGU → Public
  • Every screen serves this narrative
  • Skip technical intros, show the problem → solution
  • Use "Founder" titles, not CEO/CTO
Pitch Flow (Mandated by Advisors)
1. "Here's the problem" → Environmental incidents going unreported 2. "Citizens report" → Camera → Ghost Mode → Submit 3. "AI analyzes" → YOLO + Gemini → Structured result 4. "AI recommends" → Routing intelligence 5. "AI doesn't act alone" → LGU officer reviews in Kanban 6. "Officer takes action" → Status flow: NEW → RESOLVED 7. "Public sees results" → Public Record with map
